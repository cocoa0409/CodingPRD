=== ROLES ===
- name: DistrictAdministrator
  description: District staff who run formation, the assessment roll, collections, transparency filings and the district lifecycle. Broadest write surface, but cannot approve a work plan, resolve a dispute
    or audit an assessment statement.
  identity: opaque
  exclusive_operations:
  - POST /districts
  - POST /districts/{id}/boundary-revisions
  - POST /districts/{id}/dmo-coordination
  - POST /districts/{id}/lifecycle-advances
  - POST /lodging-businesses
  - POST /lodging-businesses/{id}/revisions
  - POST /petition-drives
  - POST /petition-drives/{id}/tally
  - POST /petition-drives/{id}/certification
  - POST /assessment-periods
  - POST /assessment-periods/{id}/statement-generation
  - POST /assessment-periods/{id}/closure
  - POST /assessment-periods/{id}/delinquency-sweep
  - POST /assessment-statements/{id}/remittance-reversals
  - POST /annual-work-plans
  - POST /transparency-records
  - POST /transparency-records/{id}/advance
  - POST /_clock/set_current_utc
  - GET /assessment-periods/{id}/statements
  shared_operations:
  - POST /petition-drives/{id}/signatures (with LodgingOperator)
  - POST /petition-signatures/{id}/withdrawal (with LodgingOperator)
  - POST /assessment-statements/{id}/filings (with LodgingOperator)
  - POST /assessment-statements/{id}/amendments (with LodgingOperator)
  - POST /assessment-statements/{id}/remittances (with LodgingOperator)
  - POST /assessment-disputes (with LodgingOperator)
  - POST /annual-work-plans/{id}/amendments (with BoardMember)
  - POST /marketing-programs (with DmoLiaison)
  - POST /marketing-programs/{id}/launch (with DmoLiaison)
  - POST /marketing-programs/{id}/closure (with DmoLiaison)
  - POST /room-night-claims/{id}/verification (with DmoLiaison)
  - all GET endpoints
- name: BoardMember
  description: Member of the district board. Sole authority to sponsor, approve, return and close an annual budget and work plan; the same board member may not both sponsor and approve the same plan.
  identity: opaque
  exclusive_operations:
  - POST /annual-work-plans/{id}/board-actions
  shared_operations:
  - POST /annual-work-plans/{id}/amendments (with DistrictAdministrator)
  - GET /districts, GET /districts/{id}, GET /districts/{id}/financial-summary
  - GET /districts/{id}/lodging-businesses, GET /districts/{id}/petition-drives, GET /districts/{id}/assessment-periods, GET /districts/{id}/annual-work-plans, GET /districts/{id}/transparency-records
  - GET /petition-drives/{id}, GET /petition-drives/{id}/signatures, GET /petition-signatures/{id}
  - GET /assessment-periods/{id}, GET /annual-work-plans/{id}, GET /annual-work-plans/{id}/marketing-programs
  - GET /marketing-programs/{id}, GET /transparency-records/{id}, GET /lodging-businesses/{id}, GET /lodging-businesses/{id}/petition-signatures
- name: LodgingOperator
  description: The lodging business itself, acting through its operator. Files and amends its own assessment statements, remits payment, signs and withdraws petition signatures, submits room-night claims
    and disputes its own assessments. X-User-ID is the LodgingBusiness id, and every write is ownership-checked against it.
  identity: entity_backed:LodgingBusiness
  exclusive_operations: []
  shared_operations:
  - POST /petition-drives/{id}/signatures (with DistrictAdministrator)
  - POST /petition-signatures/{id}/withdrawal (with DistrictAdministrator)
  - POST /assessment-statements/{id}/filings (with DistrictAdministrator)
  - POST /assessment-statements/{id}/amendments (with DistrictAdministrator)
  - POST /assessment-statements/{id}/remittances (with DistrictAdministrator)
  - POST /assessment-disputes (with DistrictAdministrator)
  - POST /assessment-disputes/{id}/proceedings, actions SUBMIT_RESPONSE, APPEAL and WITHDRAW only (with HearingOfficer, who holds OPEN_REVIEW and REQUEST_INFO)
  - POST /marketing-programs/{id}/room-night-claims (with DmoLiaison)
  - GET on its own LodgingBusiness, statements, remittances, signatures, claims and disputes
  - GET /districts, GET /districts/{id}, GET /districts/{id}/financial-summary, GET /districts/{id}/transparency-records, GET /transparency-records/{id}
- name: DmoLiaison
  description: Staff of the destination marketing organization coordinating with the district. Runs marketing programs and verifies the room-night claims that feed performance measurement, but has no authority
    over assessments, collections or the budget.
  identity: opaque
  exclusive_operations: []
  shared_operations:
  - POST /marketing-programs (with DistrictAdministrator)
  - POST /marketing-programs/{id}/launch (with DistrictAdministrator)
  - POST /marketing-programs/{id}/closure (with DistrictAdministrator)
  - POST /marketing-programs/{id}/room-night-claims (with LodgingOperator)
  - POST /room-night-claims/{id}/verification (with DistrictAdministrator)
  - GET /districts, GET /districts/{id}, GET /districts/{id}/annual-work-plans, GET /annual-work-plans/{id}, GET /annual-work-plans/{id}/marketing-programs, GET /marketing-programs/{id}, GET /marketing-programs/{id}/room-night-claims,
    GET /room-night-claims/{id}, GET /lodging-businesses/{id}/room-night-claims
- name: HearingOfficer
  description: Independent officer who hears disputes over the assessment calculation, exempt-property determinations and boundary determinations. Sole authority to resolve a dispute, and therefore the
    only role that can grant an adjustment against a statement.
  identity: opaque
  exclusive_operations:
  - POST /assessment-disputes/{id}/resolution
  - POST /assessment-disputes/{id}/proceedings, actions OPEN_REVIEW and REQUEST_INFO
  shared_operations:
  - GET /assessment-disputes/{id}, GET /assessment-statements/{id}, GET /assessment-statements/{id}/disputes, GET /assessment-periods/{id}/statements, GET /lodging-businesses/{id}, GET /lodging-businesses/{id}/assessment-statements,
    GET /lodging-businesses/{id}/disputes
  - GET /districts, GET /districts/{id}, GET /districts/{id}/lodging-businesses
- name: IndependentAuditor
  description: External auditor engaged for the statutory financial audit. Sole authority to audit and certify assessment statements; the same auditor id may not both audit and certify one statement.
  identity: opaque
  exclusive_operations:
  - POST /assessment-statements/{id}/audit-certification
  shared_operations:
  - GET /districts, GET /districts/{id}, GET /districts/{id}/financial-summary and every district sub-resource list
  - GET /assessment-periods/{id}, GET /assessment-periods/{id}/statements, GET /assessment-statements/{id}, GET /assessment-statements/{id}/remittances, GET /remittances/{id}
  - GET /annual-work-plans/{id}, GET /marketing-programs/{id}, GET /room-night-claims/{id}, GET /transparency-records/{id}
- name: PublicViewer
  description: 'Any member of the public. Reads only what the transparency requirements oblige the district to publish: the district record, its published financial summary, its work plans, its petition
    drives, its transparency records and its marketing program performance. These endpoints accept requests with no headers at all.'
  identity: opaque
  exclusive_operations: []
  shared_operations:
  - GET /districts
  - GET /districts/{id}
  - GET /districts/{id}/financial-summary
  - GET /districts/{id}/petition-drives
  - GET /districts/{id}/annual-work-plans
  - GET /districts/{id}/transparency-records
  - GET /transparency-records/{id}
  - GET /petition-drives/{id}
  - GET /annual-work-plans/{id}
  - GET /marketing-programs/{id}
